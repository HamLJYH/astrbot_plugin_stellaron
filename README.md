# 崩坏：星穹铁道金句插件 (astrbot_plugin_stellaron)

一个在 AstrBot 中使用的小插件，输入 `/崩铁` 可以随机输出游戏《崩坏：星穹铁道》中的金句。

## 功能

- **随机金句**：输入 `/崩铁 金句` 随机输出一条金句
- **自定义添加**：输入 `/崩铁 添加` 添加自己的金句
- **删除金句**：输入 `/崩铁 删除` 删除自定义金句
- **列表查看**：输入 `/崩铁 列表` 查看所有自定义金句
- **统计分析**：输入 `/崩铁 统计` 查看金句统计

## 安装

1. 将本插件文件夹复制到 AstrBot 的 `data/plugins/` 目录下
2. 重启 AstrBot 或热重载插件

## 指令

| 指令 | 说明 | 示例 |
|------|------|------|
| `/崩铁 金句` | 随机输出一条金句 | `/崩铁 金句` |
| `/崩铁 添加 <内容> [角色] [来源]` | 添加自定义金句 | `/崩铁 添加 "规则就是用来打破的" 开拓者` |
| `/崩铁 删除 <关键词>` | 删除包含关键词的自定义金句 | `/崩铁 删除 史瓦罗` |
| `/崩铁 列表 [页码]` | 查看自定义金句列表 | `/崩铁 列表 2` |
| `/崩铁 统计` | 查看金句统计 | `/崩铁 统计` |
| `/崩铁 帮助` | 显示帮助信息 | `/崩铁 帮助` |

本插件指令形成了指令组，如忘记指令，可输入 `/崩铁` 来让系统自动显示出补全的指令组。

## 内置金句

本插件内置了多条经典金句。

## 自定义金句

自定义金句保存在插件目录的 `custom_quotes.json` 文件中，格式如下：

```json
[
  {
    "content": "金句内容",
    "character": "角色名",
    "source": "来源"
  }
]
```
