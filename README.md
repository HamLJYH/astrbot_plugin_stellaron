# astrbot_plugin_stellaron
一个在AstrBot中可以使用的一个小插件，输入/崩铁可以随机输出游戏《崩坏·星穹铁道》中的金句

## 功能

- 随机金句：输入 `/崩铁` 随机输出一条金句
- 自定义添加：输入 `/崩铁添加` 添加自己的金句
- 删除金句：输入 `/崩铁删除` 删除自定义金句
- 列表查看：输入 `/崩铁列表` 查看所有自定义金句
- 统计分析：输入 `/崩铁统计` 查看金句统计

## 安装

1. 将本插件文件夹复制到 AstrBot 的 `data/plugins/` 目录下
2. 重启 AstrBot 或热重载插件

## 指令

| 指令 | 说明 | 示例 |
|------|------|------|
| `/崩铁` | 随机输出一条金句 | `/崩铁` |
| `/崩铁添加 <内容> [角色] [来源]` | 添加自定义金句 | `/崩铁添加 "规则就是用来打破的" 开拓者` |
| `/崩铁删除 <关键词>` | 删除包含关键词的自定义金句 | `/崩铁删除 史瓦罗` |
| `/崩铁列表 [页码]` | 查看自定义金句列表 | `/崩铁列表 2` |
| `/崩铁统计` | 查看金句统计 | `/崩铁统计` |
| `/崩铁帮助` | 显示帮助信息 | `/崩铁帮助` |

- 景元、刃、真理医生、砂金、流萤
- 三月七、姬子、瓦尔特、布洛妮娅
- 青雀、虎克、杰帕德、娜塔莎
- 希儿、罗刹、克拉拉、黑天鹅
- 黄泉、知更鸟、丹恒、银狼
- 星期日、飞霄、翡翠、托帕
- 阮梅、藿藿、寒鸦、雪衣
- 花火、波提欧、乱破、忘归人
- 那刻夏、遐蝶、万敌、白厄
- 阿格莱雅、缇宝、赛飞儿、风堇
- 来古士、大黑塔 等

## 自定义金句

自定义金句保存在插件目录的 `custom_quotes.json` 文件中，格式如下：

```json
[
  {
    "content": "金句内容",
    "character": "角色名",
    "source": "来源"
  }
]
```
